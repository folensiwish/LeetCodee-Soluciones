# LeetCode Solutions — Blind 75

Soluciones personales a los problemas del Blind 75, organizadas por patrón algorítmico.
Cada solución incluye el razonamiento detrás del enfoque, no solo el código.

## Formato de cada solución
Cada archivo incluye:
- Patrón utilizado
- Por qué ese enfoque
- Explicacion paso a paso como lo resolvi
- Casos bordes considerados
